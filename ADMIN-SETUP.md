# Адмін-панель — інструкція

## Як отримати собі права адміна (один раз)

Права адміна навмисно **не можна** видати собі з самої гри (щоб ніхто інший не міг
собі їх привласнити) — тільки вручну через Firebase Console.

1. Firebase Console → ваш проєкт → **Authentication** → вкладка **Users**
2. Знайдіть свій акаунт (по email виду `ваш_нік@ukrmova.app`) і скопіюйте його **User UID**
3. Firebase Console → **Realtime Database** → вкладка **Data**
4. Наведіть на корінь бази, натисніть "+" щоб додати дочірній вузол → назва `admins`
5. Всередині `admins` додайте ще один вузол → назва — **ваш скопійований UID**, значення — `true` (тип boolean)

Після цього зайдіть у гру під своїм акаунтом — на головному екрані з'явиться кнопка
**🛠️ АДМІН-ПАНЕЛЬ**.

## Що є в адмін-панелі

### 📝 Тести
Створення нових тестів: назва + будь-яка кількість питань (текст питання, правильна
відповідь, 1-3 неправильні відповіді). Після збереження тест одразу з'являється у
грі в розділі **"Додаткові тести"** — доступний усім гравцям без жодних оновлень коду.
Тести можна видаляти.

### 👥 Гравці
Пошук гравця за ніком, нарахування/списання грошей, повне видалення гравця з бази
гри (сам логін/пароль в Firebase Authentication при цьому не видаляється — це
робиться окремо в Firebase Console → Authentication → Users, якщо потрібно
заблокувати вхід повністю).

### 💬 Підтримка
Перегляд усіх повідомлень від гравців і відповідь прямо з панелі (раніше це
доводилось робити вручну через Firebase Console).

### 📊 Результати
Список усіх пройдених тестів усіх гравців: нік, назва тесту, дата/час, кількість
правильних/неправильних відповідей. Пошук за ніком або назвою тесту. Ці записи
створюються автоматично щоразу, коли гравець завершує тест — незалежно від
скріншота, тому вчитель може звірити результат навіть якщо скріншот загубився.

## Екран результату для учня

Після завершення будь-якого тесту гравець бачить екран-сертифікат з:
нікнеймом, назвою тесту, датою й часом, кількістю правильних/неправильних
відповідей і відсотком. Екран спеціально зроблений таким, щоб його було зручно
сфотографувати/заскріншотити і надіслати вчителю.
